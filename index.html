Current research

life-origins-traversal In progress

Most origin-of-life simulations pick one set of conditions, run for a long time and hope life appears. This project asks a different question: under which conditions does life emerge, and under which does it never emerge? Instead of waiting for chance, a computer tests every set of conditions in an ordered, never-repeating sequence and maps the boundary between ordinary chemistry and self-replicating, self-sustaining, compartmentalised chemistry, a "phase diagram of life".

Where it stands (October 2026):

  1. A minimal stochastic protocell model with six conditions, including a copying-error threshold, a rare origin event and a control dimension that has no effect.
  2. An ordered testing engine: a permanent archive so no condition is simulated twice, Sobol low-discrepancy coverage, monotone inference, sequential testing and boundary refinement.
  3. A benchmark against random search with brute-force ground truth, now running on an Intel Arc Pro B70. An early pilot showed the first engine design did not beat random search; the revised design is slightly ahead on the hardest conditions. Full results will be published in the repository.
