Research results

Life Origins Traversal · Completed · October 2026

The question: under which environments can non-living chemistry climb the ladder of life, and where does it stall? Instead of waiting for one long simulation to get lucky, an ordered, never-repeating search (COMPASS) maps the boundary across 13 environmental variables. The chemistry is fully bottom-up, with nothing living put in, and uses a 2-letter (0/1) alphabet.

Main conclusions

  1. 01

    Each step up the ladder narrows the possible environments sharply. Activated building blocks appear in about 45% of the environments searched, and persistent chains in about 8–16%. Heredity by template copying appears only in a narrow class of environments (5 confirmed), and heredity inside vesicles in 4 environments found by the search.

  2. 02

    The environments at the top are cool to mild, slowly flushed, enclosed pools. They have temperature cycles of days to weeks that cross the melting point of short double strands, and near-neutral to slightly acidic water. Among real settings, closed-basin cool lakes match best; vents do not.

  3. 03

    One stable environment of this kind could carry the chemistry through every level reached. Consecutive levels showed no conflicting requirements (0 conflicts in 114 comparisons). The hardest step is having heredity and stable membranes in the same place: strongly acidic heredity environments cannot hold any membrane, as measured for fatty-acid vesicles.

  4. 04

    Coupled protocells arise wherever heredity and vesicles coexist (298 of 435 runs). The ladder stops before Darwinian evolution: copying families sweep once, then copying refills every vesicle to the same load, so no heritable variation remains. Prediction: sustained evolution needs a sequence-dependent trait that copying does not erase.

  5. 05

    The method, COMPASS, needs 1.6–8× fewer simulations than Sobol or random sampling for the same map accuracy on six test models, up to 29 dimensions. The saving held at 20–30 dimensions. It does not raise hits per simulation uniformly; its proven gain is map accuracy per simulation.

Limits. This is a model, not life. Heredity in the model relies on template copying about 10⁹–10¹¹ times faster than measured non-enzymatic chemistry; at measured rates it does not start from scratch, so all heredity results are conditional on fast copying. Each paper states which conclusions follow from the model's assumptions and which are derived.

Gokyona Environment

A side product: the research engine as a platform you can run yourself.

An origin-of-life simulation platform that runs on your own computer, with a live web page. Starting from simple feedstock, it simulates the whole chemical chain: environment → activated monomers → chains → template copying with errors → vesicles that enclose, grow, divide and wash out → optional selection on a sequence trait.

  • →

    The engine of paper 2. With one 64-bit word per chain it is bit-identical to the paper's code, and it extends to much longer sequences.

  • →

    Live progress, simulated time, and a Darwin panel that compares a real half with a control half and tracks lineages.

  • →

    Detects the GPU (Intel, NVIDIA, Apple) or falls back to the CPU, and sizes itself to the available memory.

Download v1.0 (zip)Release pageSource and docs

Needs Python 3 and PyTorch. Unzip, then inside the unzipped folder (or install the wheel with pip install):

python3 -m venv .venv && . .venv/bin/activate
pip install torch      # see pytorch.org for your GPU
pip install .
gokyona-env            # opens http://localhost:9300

Pick a preset such as Darwin demo, then Create and Start. Data are kept in ~/.gokyona-env; the server listens on this computer only.
